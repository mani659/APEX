# RC008 Study 002: V1 Context-Rescue Closure

## Objective
Formally close the current RC008 investigation into whether the rejected Apex Version 1 Behavioral Event can be rescued through conventional market-context selection.

## Background
RC007 established that the isolated V1 Behavioral Event has negative standalone expectancy, grid expansion contributes nothing, and the high win rate hides severe tail risk. RC008 Study 001 subsequently tested whether ordinary market context (Volatility, Trend, Liquidity, Pre-event Path, Temporal) could selectively identify a profitable subset of this event. 

The study found:
- No context category produced a meaningful effect size.
- All observed effect sizes remained below predefined practical thresholds (|d| < 0.2).
- Conditional win rates remained weak across all quartiles.
- Conditional mean PnL remained negative across all tested partitions.

## Primary Scientific Conclusion
The evidence does **not** support the hypothesis that the rejected V1 Behavioral Event can be converted into a viable trading edge through conventional market-context filtering.

> The V1 Event + Context-Filtering rescue path is CLOSED.

## What Is Now Rejected
1. The V1 Behavioral Event does not demonstrate standalone positive alpha.
2. Grid recovery does not explain the historical result.
3. Frozen asymmetric exits do not constitute durable predictive alpha.
4. Standard volatility context does not rescue the event.
5. Standard trend context does not rescue the event.
6. Standard participation/liquidity context does not rescue the event.
7. Standard pre-event path context does not rescue the event.
8. Standard temporal context does not rescue the event.

## What Is NOT Rejected
It has NOT been concluded that mean reversion does not exist, exhaustion behaviour does not exist, market context is useless, selective trading is impossible, cross-market relationships are useless, machine learning cannot discover useful structure, or that *another* behavioral event cannot possess alpha. Only the current V1 event and its tested context-rescue approach are rejected.

## Important Scientific Boundary
- **Rejected:** "Find a profitable subset of the current V1 Behavioral Event using conventional context filters."
- **Still Open:** "Determine whether a different market behavior contains genuine predictive alpha."

This distinction prevents future research from quietly recycling the same failed formulation under different feature names.

## Campaign Status
**RC008 V1 Context-Rescue Investigation: CLOSED — NOT SUPPORTED**

## Next Research Boundary
The next campaign may investigate a **new behavioral formulation** rather than further filtering the rejected V1 event. It must begin from the empirical baseline established by RC007 and RC008. No new behavioral hypothesis should be assumed in advance.

## Final Verdict
**NOT SUPPORTED**

The current V1 Behavioral Event cannot be rescued into a credible trading edge through the tested conventional market-context variables. The V1 rescue path is therefore permanently closed. Future research must search for a genuinely different behavioral formulation rather than adding further filters to the rejected one.
