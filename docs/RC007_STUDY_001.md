# RC007 Study 001: Experimental Design — Entry Isolation Protocol

## Scientific Objective

Design a controlled experiment that isolates the statistical quality of the Apex behavioural entry signal from every downstream recovery mechanism.

The purpose of this study is to define the experimental protocol before executing any statistical analysis.

No software modifications or parameter optimization are permitted.

---

# Background

RC001–RC006 validated:

- Behavioural hypothesis
- Mathematical primitives
- Reference implementation
- Deterministic execution
- Scientific telemetry
- Platform qualification

The remaining unknown is whether the behavioural entry itself possesses predictive power independent of inventory management.

---

# Experimental Principle

The experiment shall evaluate only the **first trade** generated by a valid behavioural signal.

Everything that happens after the initial execution must be removed from the analysis.

The entry itself becomes the experimental subject.

---

# Experimental Configuration

For every valid behavioural signal:

- Grid expansion = Disabled
- Additional entries = Disabled
- Basket recovery = Disabled
- Inventory averaging = Disabled
- Dynamic R-target scaling = Disabled

Exactly one position may exist for one behavioural event.

---

# Trade Lifecycle

Each experimental trade follows the same deterministic lifecycle:

Behavioural Event
↓

Context Validation

↓

Permission

↓

Single Entry

↓

Trade Observation

↓

Exit

No additional intervention is allowed.

---

# Measurements

For every trade record the following:

## Entry

- Historical timestamp
- Symbol
- Direction
- Entry price
- ATR
- Behavioural displacement
- Participation score

---

## During Trade

Continuously calculate:

- Maximum Adverse Excursion (MAE)
- Maximum Favorable Excursion (MFE)
- Time to MAE
- Time to MFE
- Maximum holding duration

---

## Exit

Record:

- Exit price
- Exit timestamp
- Exit reason
- Profit/Loss
- R-Multiple
- Holding time

---

# Exit Models

The objective of RC007 is not to optimize exits.

Therefore multiple exit models should be evaluated independently.

Recommended models:

### Model A

Fixed Stop Loss
Fixed Take Profit

### Model B

ATR Stop
ATR Target

### Model C

Time Exit

Close after N bars regardless of profit.

### Model D

Maximum Excursion Only

No production exit.

Measure only theoretical MAE and MFE.

---

# Statistical Outputs

Generate:

- MAE distribution
- MFE distribution
- Expectancy
- Win rate
- Average R
- Median R
- Holding-time distribution
- MAE vs MFE scatter analysis

---

# Acceptance Criteria

RC007 succeeds if it can answer:

1. Does the entry possess positive expectancy?

2. How much adverse movement normally occurs before profit?

3. What reward is typically available?

4. Is the edge naturally asymmetric?

5. Does the raw entry justify any recovery mechanism?

---

# Constitutional Constraints

Throughout this experiment:

- No parameter optimization
- No behavioural modifications
- No ML
- No market context filters
- No cross-asset normalization
- No grid
- No basket management

Only the behavioural entry is under investigation.

---

# Expected Deliverables

- Entry Isolation Dataset
- MAE Report
- MFE Report
- Expectancy Report
- Raw Entry Alpha Report

---

# Success Definition

At the conclusion of RC007 Study 001, the Apex project should know—with statistical evidence rather than assumption—whether its behavioural entry is genuinely predictive before any recovery or position management is applied.

This establishes the scientific foundation for all future research.
