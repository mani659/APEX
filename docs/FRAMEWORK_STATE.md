# Known Limitations

The project is operational, but the following areas remain important for long-term maintainability:

- Configuration values should remain centrally managed where practical
- Schema validation should be strengthened over time
- Multi-asset capability requires expansion in future execution and position implementations
- Structural improvements should remain incremental rather than disruptive
