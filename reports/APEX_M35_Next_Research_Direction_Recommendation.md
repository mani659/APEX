# APEX M35: Next Research Direction Recommendation

## Primary Recommendation

**Candidate 1: Session-Transition Distributional Asymmetry** (score=45/50)

**Research Question**: Do deterministic session transitions create persistent distributional asymmetry — reliable mean-reversion during low-liquidity windows versus reliable path-expansion during high-liquidity transitions — that can be characterized without localized behavioral prediction?

**Why It Is the Highest-Information-Value Direction**:
1. Builds directly on RC013 validated session-transition primitives (scientific continuity).
2. Resolves a genuinely different question from HIGH_VOL translation (novel information).
3. Uses existing EURUSD M1 data at zero cost (data feasibility, cost efficiency).
4. Session windows are deterministic and can be frozen ex-ante (ex-ante defensibility).
5. Can produce a clean negative result (falsifiability).
6. Does not reopen any closed branch (independence).

**Existing Evidence**:
- RC013 validated session transitions as structural distributional primitives.
- RC012 confirmed volatility expansion is direction-neutral.
- Post-RC013 review identified session mechanics as the highest-value existing-data opportunity.

**What Remains Unknown**:
- Whether session transitions create persistent distributional asymmetry.
- Whether the asymmetry is exploitable without localized behavioral prediction.
- How session effects interact with volatility state.

**Data Requirements**: None. Uses existing canonical EURUSD M1 data (5.5 years).

**How It Can Be Frozen Ex Ante**:
- Session windows: London Open (08:00 UTC), NY Overlap (13:00 UTC), Asian (00:00–08:00 UTC).
- Distributional tests specified before viewing outcomes.
- Walk-forward validation with expanding window.

**What Would Falsify It**:
- No statistically significant distributional differences across session windows under frozen HAC-corrected inference.
- Differences significant but too small for economic meaning.

**Why It Is Independent of Closed Branches**:
- Does not use HIGH_VOL as a predictor or filter.
- Does not test volatility translation, boundary translation, or dynamic boundaries.
- Tests a structurally different market property (time-of-day liquidity mechanics).
